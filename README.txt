เหลือเก็บ - ติดตั้งบนมือถือ Android (ทำได้จากมือถืออย่างเดียว ประมาณ 10 นาที)

ขั้นที่ 1: แตกไฟล์ zip
- เปิดแอป Files (Files by Google) > Downloads > แตะไฟล์ luakep-pwa.zip > แตกไฟล์ (Extract)
- จะได้โฟลเดอร์ pwa ที่มี 8 ไฟล์

ขั้นที่ 2: สร้างที่เก็บบน GitHub (ฟรี)
- เปิด Chrome ไปที่ github.com สมัครหรือเข้าสู่ระบบ
- แตะ + (มุมขวาบน) > New repository > ตั้งชื่อ luakep > เลือก Public > Create repository
- ในหน้า repository แตะลิงก์ "uploading an existing file"
- แตะ "choose your files" แล้วเลือกทุกไฟล์ในโฟลเดอร์ pwa (index.html, manifest.webmanifest, sw.js, icon ทั้ง 4 ไฟล์, README.txt)
- เลื่อนลงแตะ Commit changes

ขั้นที่ 3: เปิดเว็บ
- ในหน้า repository แตะ Settings > Pages (ถ้าไม่เห็นเมนู ให้เปิด "เวอร์ชันเดสก์ท็อป" ในเมนู ⋮ ของ Chrome)
- Source: Deploy from a branch > Branch: main > / (root) > Save
- รอ 1-2 นาที แล้วรีเฟรช จะเห็นลิงก์ https://ชื่อผู้ใช้.github.io/luakep/

ขั้นที่ 4: ติดตั้ง
- เปิดลิงก์นั้นใน Chrome > แตะ ⋮ > "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก" > ติดตั้ง
- ไอคอนน้องโอ่งจะอยู่บนหน้าจอ เปิดเต็มจอ ใช้ออฟไลน์ได้

อัปเดตเวอร์ชันใหม่
- อัปโหลดไฟล์ที่เปลี่ยนทับของเดิมใน GitHub แล้วเปิดแอปใหม่ 1-2 ครั้ง

ข้อควรรู้
- ข้อมูลอยู่ในมือถือเท่านั้น สำรองทุกสิ้นเดือนที่ ตั้งค่า > สำรองข้อมูล
- ถ้าถอนแอปหรือล้างข้อมูล Chrome ข้อมูลจะหาย
- ปุ่มอ่านสลิปใช้ได้เฉพาะเวอร์ชันใน Claude
- repository แบบ Public คนอื่นเห็นโค้ด แต่ไม่เห็นข้อมูลการเงินของคุณ
